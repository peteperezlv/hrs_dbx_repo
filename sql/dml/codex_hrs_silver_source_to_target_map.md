## Scope gaps

- Use Case Q5.1–Q5.2 asks about prior years of flu vaccination. No corresponding source variable or target column is defined in the provided model/specification, so these scripts do not load that measure.
- The DML prompt names `codex_` target tables, while the current files `sql/ddl/codex_create_hrs_*.sql` create unprefixed table names. The prefixed target tables must exist with the columns listed above before these DML files can run.
